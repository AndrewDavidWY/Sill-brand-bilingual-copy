# 品牌双语传播文案

把品牌海报、企业介绍和活动信息写成意思一致、表达自然的中英文文案。中文讲清观点，英文按相同事实和语气重新组织，避免生硬直译。

技能名称：`brand-bilingual-copy` · [查看技能指令](SKILL.md)

## 适合什么时候用

- 海报已经完成，需要配一段适合发布的中英文文字。
- 企业介绍或活动邀请需要两种语言同时使用。
- 旧文案修改了日期、数字或定位，需要同步检查英文。

## 开始前准备什么

- 海报、原文或本次要表达的要点。
- 目标受众、发布渠道、篇幅，以及希望读者采取的行动。
- 正式中英文名称、术语和已经确认的事实。

## 工作方式

1. 先分清图片和配文各自承担的信息。
2. 中文建立清晰观点，再补必要解释和行动引导。
3. 英文自然重写，逐项核对专名、数字、日期和事实状态。
4. 两个版本一起检查，修改时同步更新。

## 可以得到什么

- 可直接使用的中文文案与 English 文案。
- 需要确认的专有名词、暂译名称或事实缺口。

如果使用自定义 `CODEX_HOME`，请放到其 `skills/` 下。同名目录已经存在时先比较版本并保留自己的修改，不要直接覆盖。下载 ZIP 时，同样需保留完整文件结构，并把解压后的安装目录命名为技能名称。
